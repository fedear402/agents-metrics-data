Related example: Port freight IV and shock-level uncertainty
Separate example context: Five ports have shares in four shipping categories. External category shocks provide an instrument for freight use. Estimate the freight-cost slope and instrument relevance. For this toy calculation, assume independent category shocks affect cost only through freight use.
Explanation of this example: Normalize weights across ports once. Subtract weighted regional means from cost, freight and the instrument before exposure aggregation. Include intercepts in the shock regressions. Both uncertainty calculations use structural IV residuals, squared weighted instrument scores and the category-count HC1 multiplier. For relevance, the endogenous shock-level regressor is aggregated regional instrument exposure. It is not the raw external shock. Check both shock slopes against their regional counterparts. Effective category count uses all exposure masses and can be fractional.
```stata
version 19.0
clear all
set more off
set linesize 255
mata:
// Separate toy ports, categories and independent external shocks.
shares=(.5,.3,.1,.1\.1,.5,.3,.1\.2,.1,.5,.2\.1,.2,.2,.5\.3,.2,.1,.4)
shock=(-1\.4\1.7\-.2)
port_weight=(1\2\1\3\2)
port_weight=port_weight/sum(port_weight)
instrument=shares*shock
freight=1.2*instrument+(.2\-.4\.6\-.2\.3)
cost=1.7*freight+(.3\.1\-.2\.4\-.3)
// Center every regional variable before exposure aggregation.
regional=(cost,freight,instrument)
centered=regional:-port_weight'*regional
mass=shares'*port_weight
aggregated=(shares'*(port_weight:*centered)):/mass
assert(max(abs(mass'*aggregated))<1e-10)
category_count=rows(shock)
estimates=J(2,2,.)
for (equation=1;equation<=2;equation++) {
    dependent=aggregated[,equation]
    endogenous=aggregated[,equation+1]
    // Relevance uses aggregated instrument as the endogenous regressor.
    regressors=(J(category_count,1,1),endogenous)
    instruments=(J(category_count,1,1),shock)
    cross=instruments'*(mass:*regressors)
    inverse=luinv(cross)
    beta=inverse*instruments'*(mass:*dependent)
    // Structural residuals retain the endogenous regressor itself.
    residual=dependent-regressors*beta
    scores=instruments:*(mass:*residual)
    // One weight in each score gives squared weights in its outer product.
    covariance=category_count/(category_count-2)*inverse*(scores'*scores)*inverse'
    estimates[equation,]=(beta[2],sqrt(covariance[2,2]))
}
regional_effect=sum(port_weight:*centered[,3]:*centered[,1])/sum(port_weight:*centered[,3]:*centered[,2])
regional_relevance=sum(port_weight:*centered[,3]:*centered[,2])/sum(port_weight:*centered[,3]:^2)
assert(max(abs(estimates[,1]-(regional_effect\regional_relevance)))<1e-10)
printf("ANSWER: freight_slope estimate=%21.15g se=%21.15g n_obs=%9.0f\n",estimates[1,1],estimates[1,2],category_count)
printf("ANSWER: freight_relevance estimate=%21.15g se=%21.15g n_obs=%9.0f\n",estimates[2,1],estimates[2,2],category_count)
printf("ANSWER: effective_categories estimate=%21.15g se=NA n_obs=%9.0f\n",1/sum(mass:^2),category_count)
end
```

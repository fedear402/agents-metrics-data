A smaller example uses separate synthetic data to illustrate the method.
```r
# Two travel alternatives and one cost coefficient form a smaller choice problem.
set.seed(434)
n <- 120
cost0 <- runif(n,.2,3); cost1 <- runif(n,.2,3)
dx <- cost1-cost0
y <- rbinom(n,1,plogis(.3-.9*dx))
write.csv(data.frame(cost0,cost1,y), 'example_r_data.csv',row.names=FALSE)
fit <- glm(y~dx,family=binomial())
a <- unname(coef(fit)[1]); b <- unname(coef(fit)[2])
old <- cbind(b*cost0,a+b*cost1)
policy <- cbind(b*cost0,a+b*cost1*.8)
lse <- function(u) {m<-apply(u,1,max);m+log(rowSums(exp(u-m)))}
weights <- seq(1,2,length.out=n)
gain <- (lse(policy)-lse(old))/(-b)
print(list(cost_coefficient=b,welfare_gain=weighted.mean(gain,weights)))
write.csv(data.frame(term=c('cost_coefficient','welfare_gain'),estimate=c(b,weighted.mean(gain,weights))), 'example_r_output.csv',row.names=FALSE)
```

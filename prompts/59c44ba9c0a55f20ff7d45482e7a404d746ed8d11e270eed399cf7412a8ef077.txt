Explanation of this example: The design contains an intercept and a high-group indicator. The contrast [0,1] selects the high-minus-low difference in each outcome. First project each observation's coefficient contribution onto this contrast. Then form the joint covariance from the two resulting outcome contributions. Each contribution contains one weight, so its outer product contains the squared weight. The cross-outcome entry uses both residuals from the same household. The delta-method gradient combines both variances and their covariance. Use no degrees-of-freedom correction. A causal ratio interpretation requires additional identification assumptions.

import json
import numpy as np

def report(rows):
    output = {"task_id": EXAMPLE_ID, "estimates": rows}
    with open("example_result.json", "w") as stream:
        json.dump(output, stream, indent=2, allow_nan=False)

EXAMPLE_ID = "water_filter_weighted_groups"
# These fixed teaching data are separate from the scored task.
above = np.repeat([0., 1.], 6)
weights = np.array([1.,2.,1.,3.,2.,1.,2.,1.,3.,1.,2.,2.])
filter_use = np.array([0.,0.,1.,0.,0.,1.,1.,1.,0.,1.,1.,1.])
clean_days = np.array([8.,10.,12.,9.,11.,13.,16.,18.,11.,17.,20.,19.])
X = np.column_stack([np.ones(len(above)), above])
Y = np.column_stack([clean_days, filter_use])
bread = np.linalg.inv(X.T @ (weights[:, None] * X))
coefficients = bread @ X.T @ (weights[:, None] * Y)
residuals = Y - X @ coefficients
# With intercept and group indicator, this contrast selects high minus low.
contrast = np.array([0., 1.])
jumps = contrast @ coefficients
# Each observation contributes to the two selected outcome contrasts.
loading = weights * (X @ bread @ contrast)
influence = loading[:, None] * residuals
joint = influence.T @ influence
outcome_jump, takeup_jump = jumps
gradient = np.array([1 / takeup_jump, -outcome_jump / takeup_jump**2])
ratio_se = np.sqrt(gradient @ joint @ gradient)
rows = [
    {"term": "clean_days_difference", "estimate": float(outcome_jump), "se": float(np.sqrt(joint[0,0])), "n_obs": 12},
    {"term": "filter_use_difference", "estimate": float(takeup_jump), "se": float(np.sqrt(joint[1,1])), "n_obs": 12},
    {"term": "filter_ratio", "estimate": float(outcome_jump / takeup_jump), "se": float(ratio_se), "n_obs": 12},
    {"term": "difference_covariance", "estimate": float(joint[0,1]), "se": None, "n_obs": 12},
]
report(rows)

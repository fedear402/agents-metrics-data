A smaller example uses separate synthetic data to illustrate the method.
```stata
version 14
clear all
set more off
* Two travel alternatives and one cost coefficient form a smaller choice problem.
set seed 434
set obs 120
generate double cost0 = .2+2.8*runiform()
generate double cost1 = .2+2.8*runiform()
generate double dx = cost1-cost0
generate byte y = runiform()<invlogit(.3-.9*dx)
export delimited cost0 cost1 y using "example_stata_data.csv", replace
quietly logit y dx
scalar a = _b[_cons]
scalar b = _b[dx]
generate double u0 = b*cost0
generate double u1 = a+b*cost1
generate double v1 = a+b*cost1*.8
generate double m0 = max(u0,u1)
generate double mp = max(u0,v1)
generate double oldsum = m0+ln(exp(u0-m0)+exp(u1-m0))
generate double newsum = mp+ln(exp(u0-mp)+exp(v1-mp))
generate double gain = (newsum-oldsum)/(-b)
generate double weight = 1+(_n-1)/119
quietly summarize gain [aw=weight], meanonly
scalar wg = r(mean)
display "ANSWER: cost_coefficient estimate=" %21.15g b
display "ANSWER: welfare_gain estimate=" %21.15g wg
```

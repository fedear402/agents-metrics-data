Explanation of this example: Sort by the time column. Forecast time f is a one-based label. Select labels f-6 through f-1 inclusive. The next window contains observed times 2 through 7. It uses observed visits at time7, not the earlier forecast. No regression or forecast predictor uses the outcome at its forecast date. * Separate teaching data. Time values are one-based observation labels.
```stata
input double time visits

6 23
8 25
4 20
end
sort time
tsset time
generate double lagged_visits=L.visits
local window_levels=6
generate double forecast=.
forvalues f=7/9 {
    * Six past levels give five pairs. At f=7: (1,2),...,(5,6).
    local first_response=`f'-`window_levels'+1
    local last_response=`f'-1
    quietly regress visits lagged_visits if inrange(time,`first_response',`last_response')
    assert e(N)==`window_levels'-1
    * Forecast f uses observed visits at f-1. No time-f outcome enters fitting.
    quietly replace forecast=_b[_cons]+_b[lagged_visits]*lagged_visits if time==`f'
}
* Refit each date. Time8 uses observed time7, not forecast7.
generate double squared_error=(visits-forecast)^2 if inrange(time,7,9)
quietly summarize squared_error, meanonly
scalar rmse=sqrt(r(mean))
display "ANSWER: clinic_rmse estimate=" %21.15g rmse " se=NA n_obs=3"
forvalues f=7/9 {
    quietly summarize forecast if time==`f', meanonly
    display "ANSWER: clinic_forecast_`f' estimate=" %21.15g r(mean) " se=NA n_obs=5"
}
```

Related example: Two lagged fuel changes and cumulative shipment uncertainty
Separate example context: A delivery depot has 24 separate weekday observations. The exact columns are date, fuel_index, and shipments. The last two columns contain positive values. Regress log shipments on an intercept and the first two observed-row lags of log fuel-index changes. Report both lag coefficients and their sum. Use Bartlett Newey-West covariance with maximum lag two and correction N/(N-3). This is an association calculation.
Explanation of this example: Sort dates first. At observation t, the regressors are log(fuel[t-1])-log(fuel[t-2]) and log(fuel[t-2])-log(fuel[t-3]). The first usable outcome is observation four, leaving 21 rows. Friday-to-Monday is one observed-row step. OLS uses these aligned rows. Form HAC from chronological residual scores, using lag weights 2/3 and 1/3. Apply N/(N-3), because the model has three coefficients. The cumulative-response variance is V[1,1]+V[2,2]+2*V[1,2]. The contrast [0,1,1] excludes the intercept and includes this covariance. Keep regression lag count, HAC lag count, parameter count, and usable sample size as separate quantities.

```r
library(jsonlite)
row <- function(term, estimate, se=NULL, n_obs) {
  list(term=term, estimate=unname(as.numeric(estimate)),
       se=if (is.null(se)) NULL else unname(as.numeric(se)), n_obs=as.integer(n_obs))
}
report <- function(id, rows) {
  write_json(list(task_id=id, estimates=rows), "example_result.json",
             auto_unbox=TRUE, null="null", digits=16, pretty=TRUE)
}
# Separate teaching data: 24 observed weekdays, deliberately reversed.
days <- seq(as.Date("2024-02-01"),by="day",length.out=40)
days <- days[!as.POSIXlt(days)$wday %in% c(0,6)][1:24]
data <- data.frame(date=days,
 fuel_index=c(98,100,99,102,101,104,103,105,108,106,109,111,110,113,112,115,117,114,118,120,119,122,121,124),
 shipments=c(210,214,211,215,218,216,221,219,223,226,222,227,229,225,231,232,228,234,236,233,239,237,241,243))
data <- data[24:1,]
# Sort before differences and lags. Rows represent observed weekdays.
data <- data[order(data$date),]
data$fuel_change <- c(NA,diff(log(data$fuel_index)))
data$change_lag1 <- c(NA,head(data$fuel_change,-1))
data$change_lag2 <- c(NA,NA,head(data$fuel_change,-2))
data$log_shipments <- log(data$shipments)
# Use changes at t-1 and t-2. Differencing plus two lags removes three rows.
sample <- data[complete.cases(data[,c("log_shipments","change_lag1","change_lag2")]),]
fit <- lm(log_shipments ~ change_lag1+change_lag2,data=sample)
X <- model.matrix(fit)
coefficients <- coef(fit)
N <- nrow(X)
scores <- X*residuals(fit)
hac_lags <- 2
meat <- crossprod(scores)
for (j in seq_len(hac_lags)) {
  lag_product <- crossprod(scores[(j+1):N,,drop=FALSE],scores[1:(N-j),,drop=FALSE])
  meat <- meat+(1-j/(hac_lags+1))*(lag_product+t(lag_product))
}
bread <- solve(crossprod(X))
p <- ncol(X)
covariance <- N/(N-p)*bread%*%meat%*%bread
# Exclude the intercept. Include cross-covariances in the sum variance.
contrast <- c(0,1,1)
cumulative <- sum(contrast*coefficients)
cumulative_se <- sqrt(drop(t(contrast)%*%covariance%*%contrast))
report("depot_two_lag_hac",list(
  row("depot_cumulative",cumulative,cumulative_se,N),
  row("depot_lag1",coefficients[2],sqrt(covariance[2,2]),N),
  row("depot_lag2",coefficients[3],sqrt(covariance[3,3]),N)))
```

Separate example context: A delivery depot has 24 separate weekday observations. The exact columns are date, fuel_index, and shipments. The last two columns contain positive values. Regress log shipments on an intercept and the first two observed-row lags of log fuel-index changes. Report both lag coefficients and their sum. Use Bartlett Newey-West covariance with maximum lag two and correction N/(N-3). This is an association calculation.
Explanation of this example: Sort dates first. At observation t, the regressors are log(fuel[t-1])-log(fuel[t-2]) and log(fuel[t-2])-log(fuel[t-3]). The first usable outcome is observation four, leaving 21 rows. Friday-to-Monday is one observed-row step. OLS uses these aligned rows. Form HAC from chronological residual scores, using lag weights 2/3 and 1/3. Apply N/(N-3), because the model has three coefficients. The cumulative-response variance is V[1,1]+V[2,2]+2*V[1,2]. The contrast [0,1,1] excludes the intercept and includes this covariance. Keep regression lag count, HAC lag count, parameter count, and usable sample size as separate quantities.

```python
import json
import numpy as np
import pandas as pd

# Separate teaching data: 24 observed weekdays at a delivery depot.
data = pd.DataFrame({
    "date": pd.bdate_range("2024-02-01", periods=24),
    "fuel_index": [98, 100, 99, 102, 101, 104, 103, 105, 108, 106, 109, 111,
                   110, 113, 112, 115, 117, 114, 118, 120, 119, 122, 121, 124],
    "shipments": [210, 214, 211, 215, 218, 216, 221, 219, 223, 226, 222, 227,
                  229, 225, 231, 232, 228, 234, 236, 233, 239, 237, 241, 243],
}).iloc[::-1].copy()

# Sort before creating differences or lags. Each row is an observed weekday.
data = data.sort_values("date").reset_index(drop=True)
data["fuel_change"] = np.log(data["fuel_index"]).diff()
data["change_lag1"] = data["fuel_change"].shift(1)
data["change_lag2"] = data["fuel_change"].shift(2)
data["log_shipments"] = np.log(data["shipments"])

# At observation t, use changes at t-1 and t-2, never the change at t.
# A first difference and two lags remove the first three observations.
sample = data.dropna(subset=["log_shipments", "change_lag1", "change_lag2"])
N = len(sample)
X = np.column_stack([np.ones(N), sample["change_lag1"], sample["change_lag2"]])
y = sample["log_shipments"].to_numpy()
coefficients = np.linalg.lstsq(X, y, rcond=None)[0]
residuals = y - X @ coefficients

# Newey-West covariance. Scores stay in chronological regression-sample order.
scores = X * residuals[:, None]
hac_lags = 2
meat = scores.T @ scores
for j in range(1, hac_lags + 1):
    weight = 1 - j / (hac_lags + 1)
    lag_product = scores[j:].T @ scores[:-j]
    meat += weight * (lag_product + lag_product.T)
bread = np.linalg.inv(X.T @ X)
p = X.shape[1]  # Intercept plus two lag coefficients.
covariance = (N / (N - p)) * bread @ meat @ bread

# The intercept is excluded. The sum's variance includes both covariance terms.
contrast = np.array([0.0, 1.0, 1.0])
cumulative = float(contrast @ coefficients)
cumulative_se = float(np.sqrt(contrast @ covariance @ contrast))
rows = [
    {"term": "depot_cumulative", "estimate": cumulative, "se": cumulative_se, "n_obs": N},
    {"term": "depot_lag1", "estimate": float(coefficients[1]), "se": float(np.sqrt(covariance[1, 1])), "n_obs": N},
    {"term": "depot_lag2", "estimate": float(coefficients[2]), "se": float(np.sqrt(covariance[2, 2])), "n_obs": N},
]
output = {"task_id": "depot_two_lag_hac", "estimates": rows}
with open("example_result.json", "w") as stream:
    json.dump(output, stream, indent=2, allow_nan=False)
```

Related example: A weighted water-filter discontinuity with two group means
Separate example context: Twelve households lie on either side of a water-filter voucher threshold. This simplified illustration uses two group means. It has no running-variable slopes. The supplied unequal weights are fixed. Estimate high-minus-low differences in clean-water days and filter use, their ratio, and empirical HC0 uncertainty.
Explanation of this example: The design contains an intercept and a high-group indicator. The contrast [0,1] selects the high-minus-low difference in each outcome. First project each observation's coefficient contribution onto this contrast. Then form the joint covariance from the two resulting outcome contributions. Each contribution contains one weight, so its outer product contains the squared weight. The cross-outcome entry uses both residuals from the same household. The delta-method gradient combines both variances and their covariance. Use no degrees-of-freedom correction. A causal ratio interpretation requires additional identification assumptions.
```r
library(jsonlite)
row <- function(term, estimate, se=NULL, n_obs) {
  list(term=term, estimate=unname(as.numeric(estimate)),
       se=if (is.null(se)) NULL else unname(as.numeric(se)), n_obs=as.integer(n_obs))
}
report <- function(id, rows) {
  write_json(list(task_id=id, estimates=rows), "example_result.json",
             auto_unbox=TRUE, null="null", digits=16, pretty=TRUE)
}
# Fixed teaching data, separate from the scored task.
above <- rep(c(0,1), each=6)
weights <- c(1,2,1,3,2,1,2,1,3,1,2,2)
filter_use <- c(0,0,1,0,0,1,1,1,0,1,1,1)
clean_days <- c(8,10,12,9,11,13,16,18,11,17,20,19)
X <- cbind(1, above)
Y <- cbind(clean_days, filter_use)
bread <- solve(crossprod(X, weights*X))
coefficients <- bread %*% crossprod(X, weights*Y)
residuals <- Y-X%*%coefficients
# Intercept plus indicator: select high minus low with c(0,1).
contrast <- c(0,1)
jumps <- drop(contrast %*% coefficients)
loading <- weights * drop(X %*% bread %*% contrast)
influence <- loading * residuals
# Each contribution contains one weight. Its outer product squares the weight.
joint <- crossprod(influence)
gradient <- c(1/jumps[2], -jumps[1]/jumps[2]^2)
ratio_se <- sqrt(drop(t(gradient)%*%joint%*%gradient))
report("water_filter_weighted_groups", list(
  row("clean_days_difference",jumps[1],sqrt(joint[1,1]),12),
  row("filter_use_difference",jumps[2],sqrt(joint[2,2]),12),
  row("filter_ratio",jumps[1]/jumps[2],ratio_se,12),
  row("difference_covariance",joint[1,2],NULL,12)))
```

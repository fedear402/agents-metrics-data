Example on separate small data. This simpler example illustrates a related calculation.
```python
import numpy as np
from scipy.stats import norm
# Known coefficients in a smaller mean/scale model: mu=0.3+0.8*x, sigma=exp(0.5*z).
x=np.array([-1.0,0.0,1.0]);z=np.array([0.0,1.0,-1.0])
sigma=np.exp(0.5*z);eta=(0.3+0.8*x)/sigma
print('probabilities',np.round(norm.cdf(eta),10).tolist())
print('ame_x',round(float(np.mean(norm.pdf(eta)*0.8/sigma)),10))
```

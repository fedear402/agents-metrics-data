Related example: Port freight IV and shock-level uncertainty
Separate example context: Five ports have shares in four shipping categories. External category shocks provide an instrument for freight use. Estimate the freight-cost slope and instrument relevance. For this toy calculation, assume independent category shocks affect cost only through freight use.
Explanation of this example: Normalize weights across ports once. Subtract weighted regional means from cost, freight and the instrument before exposure aggregation. Include intercepts in the shock regressions. Both uncertainty calculations use structural IV residuals, squared weighted instrument scores and the category-count HC1 multiplier. For relevance, the endogenous shock-level regressor is aggregated regional instrument exposure. It is not the raw external shock. Check both shock slopes against their regional counterparts. Effective category count uses all exposure masses and can be fractional.
The example uses separate data and writes example_result.json. It uses the same estimates-row structure as the scored task, with its own task identifier and result names. The scored task below must read its own input.csv and write result.json.
```python
import json
import numpy as np

# Separate toy ports, shipping categories, and independent external shocks.
shares = np.array([[.5,.3,.1,.1],[.1,.5,.3,.1],[.2,.1,.5,.2],
                   [.1,.2,.2,.5],[.3,.2,.1,.4]])
shock = np.array([-1.,.4,1.7,-.2])
port_weight = np.array([1.,2.,1.,3.,2.])
port_weight /= port_weight.sum()
instrument = shares @ shock
freight = 1.2*instrument + np.array([.2,-.4,.6,-.2,.3])
cost = 1.7*freight + np.array([.3,.1,-.2,.4,-.3])

# Center ALL regional variables before exposure aggregation.
regional = np.column_stack([cost, freight, instrument])
centered = regional - port_weight @ regional
mass = port_weight @ shares
aggregated = (shares.T @ (port_weight[:,None]*centered))/mass[:,None]
assert np.allclose(mass @ aggregated, 0.)
category_count = len(shock)

def shock_iv(dependent, endogenous):
    # Include an intercept in both regressor and instrument matrices.
    regressors = np.column_stack([np.ones(category_count), endogenous])
    instruments = np.column_stack([np.ones(category_count), shock])
    cross = instruments.T @ (mass[:,None]*regressors)
    beta = np.linalg.solve(cross, instruments.T @ (mass*dependent))
    # Use structural residuals from the endogenous regressor itself.
    residual = dependent - regressors @ beta
    scores = instruments * (mass*residual)[:,None]
    inverse = np.linalg.inv(cross)
    # Analytic weights enter the score once and its outer product twice.
    hc1 = category_count/(category_count-2)
    covariance = hc1 * inverse @ (scores.T@scores) @ inverse.T
    return float(beta[1]), float(np.sqrt(covariance[1,1]))

cost_slope, cost_se = shock_iv(aggregated[:,0], aggregated[:,1])
# The relevance equation treats aggregated INSTRUMENT as endogenous.
relevance, relevance_se = shock_iv(aggregated[:,1], aggregated[:,2])
regional_slope = np.sum(port_weight*centered[:,2]*centered[:,0])/np.sum(port_weight*centered[:,2]*centered[:,1])
regional_relevance = np.sum(port_weight*centered[:,2]*centered[:,1])/np.sum(port_weight*centered[:,2]**2)
assert np.allclose([cost_slope,relevance],[regional_slope,regional_relevance])
output = {'task_id':'shift_share_clearer_separate_example', 'estimates':[
    {'term':'freight_slope','estimate':cost_slope,'se':cost_se,'n_obs':category_count},
    {'term':'freight_relevance','estimate':relevance,'se':relevance_se,'n_obs':category_count},
    {'term':'effective_categories','estimate':float(1/np.sum(mass**2)),'se':None,'n_obs':category_count}
]}
with open('example_result.json','w') as stream:
    json.dump(output,stream,indent=2,allow_nan=False)
```

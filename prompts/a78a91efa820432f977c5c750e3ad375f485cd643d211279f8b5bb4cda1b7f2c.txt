Separate example context: A clinic records nine daily visit totals in shuffled row order. Forecast times 7, 8, and 9. Each forecast uses exactly the six observed levels immediately before its date. Fit an OLS AR(1) with an intercept on the five consecutive pairs within each window. Refit at each forecast date using observed visits. Report all three forecasts and their three-date RMSE.
Explanation of this example: Sort by the time column. Forecast time f is a one-based label. Select labels f-6 through f-1 inclusive. For f=7, levels at times 1 through 6 yield five pairs: (1,2), (2,3), (3,4), (4,5), and (5,6). Use the fitted intercept and slope with observed visits at time6 to forecast time7. The next window contains observed times 2 through 7. It uses observed visits at time7, not the earlier forecast. No regression or forecast predictor uses the outcome at its forecast date. Evaluate errors after forecasting. Each forecast has n_obs=5 regression pairs. RMSE has n_obs=3 evaluated dates. A time label is not a zero-based array position. If using an array sorted from time1, label f corresponds to position f-1.
The example uses separate data and writes example_result.json. It uses the same estimates-row structure as the scored task, with its own task identifier and result names. The scored task below must read its own input.csv and write result.json.
```python
import json
import numpy as np
import pandas as pd

# Separate teaching data. The time values are one-based observation labels.
data = pd.DataFrame({
    "time": [3, 1, 7, 5, 9, 2, 6, 8, 4],
    "visits": [24, 21, 30, 27, 33, 18, 23, 25, 20],
}).sort_values("time").reset_index(drop=True)

window_levels = 6
forecast_times = [7, 8, 9]
forecasts = {}
for f in forecast_times:
    # f is a time label, not a zero-based array position.
    # For f=7, the six training levels have times 1,2,3,4,5,6.
    history = data.loc[data["time"].between(f - window_levels, f - 1)].copy()
    assert history["time"].tolist() == list(range(f - window_levels, f))
    levels = history["visits"].to_numpy(dtype=float)

    # Six levels give five pairs. For f=7: (1,2),...,(5,6).
    lagged = levels[:-1]
    current = levels[1:]
    X = np.column_stack([np.ones(len(lagged)), lagged])
    coefficients = np.linalg.lstsq(X, current, rcond=None)[0]
    assert len(current) == window_levels - 1

    # Forecast f from observed visits at f-1. Observed visits at f are excluded.
    forecasts[f] = float(coefficients @ np.array([1.0, levels[-1]]))

# Refit for every date. The f=8 fit uses observed visits at time7, not forecast7.
# Read the held-out outcomes only after producing their forecasts.
actual = data.set_index("time").loc[forecast_times, "visits"].to_numpy(dtype=float)
predicted = np.array([forecasts[f] for f in forecast_times])
rmse = float(np.sqrt(np.mean((actual - predicted) ** 2)))
rows = [
    {"term": "clinic_rmse", "estimate": rmse, "se": None, "n_obs": len(forecast_times)},
    *[{"term": f"clinic_forecast_{f}", "estimate": forecasts[f], "se": None, "n_obs": window_levels - 1}
      for f in forecast_times],
]
output = {"task_id": "clinic_three_rolling_forecasts", "estimates": rows}
with open("example_result.json", "w") as stream:
    json.dump(output, stream, indent=2, allow_nan=False)
```

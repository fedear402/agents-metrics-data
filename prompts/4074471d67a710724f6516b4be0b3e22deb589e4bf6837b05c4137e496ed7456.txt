Two separate groups have hourly wages and experience. Decompose group 1 minus group 0 mean wages using group 0 regression coefficients as reference.

The explained component changes mean covariates while holding reference coefficients fixed. The unexplained component changes coefficients at group 1 means. Include the intercept in the latter calculation.

The target has another covariate and an individual covariate contribution.

This separate example writes example_result.json. The task reads input.csv and reports its own results.

```python
import json
import numpy as np

def report(**values):
    rows = [
        {'term': 'wage_gap', 'estimate': float(values['gap']), 'se': None, 'n_obs': int(values['workers'])},
        {'term': 'explained_gap', 'estimate': float(values['explained']), 'se': None, 'n_obs': int(values['workers'])},
        {'term': 'unexplained_gap', 'estimate': float(values['unexplained']), 'se': None, 'n_obs': int(values['workers'])},
    ]
    output = {'task_id': 'oaxaca_separate_example', 'estimates': rows}
    with open('example_result.json', 'w') as stream:
        json.dump(output, stream, indent=2, allow_nan=False)

experience0 = np.array([1.,2.,4.,6.,7.])
experience1 = np.array([2.,3.,5.,7.,9.])
wage0 = np.array([11.,13.,14.,18.,19.])
wage1 = np.array([14.,17.,21.,22.,28.])
X0 = np.column_stack([np.ones(5),experience0])
X1 = np.column_stack([np.ones(5),experience1])
b0 = np.linalg.lstsq(X0,wage0,rcond=None)[0]
b1 = np.linalg.lstsq(X1,wage1,rcond=None)[0]
explained = (X1.mean(axis=0)-X0.mean(axis=0))@b0
unexplained = X1.mean(axis=0)@(b1-b0)
gap = wage1.mean()-wage0.mean()
assert np.isclose(gap,explained+unexplained)
report(gap=gap, explained=explained, unexplained=unexplained, workers=10)
```

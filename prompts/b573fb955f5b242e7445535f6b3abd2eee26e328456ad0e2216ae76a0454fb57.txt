Separate example context: Ten separate teaching farms provide two encouragement assignments, fertilizer dose, and harvest. Assume both assignments satisfy the instrument conditions. Include an intercept and invert the homoskedastic joint F test.
Explanation of this example: Let q count excluded instruments and df=n-p count residual degrees of freedom in the unrestricted regression. F(beta)=((SSR_R(beta)-SSR_U(beta))/q)/(SSR_U(beta)/df). Acceptance is SSR_R-(1+q*critical/df)*SSR_U<=0. Expand this into A*beta^2+B*beta+C<=0. For two distinct real boundaries, A>0 accepts the interval and A<0 accepts the outer rays. Derive the sign and membership from the example data. Other data can require separate degenerate-set handling.

```python
import json
import numpy as np
from scipy.stats import f

# Ten separate teaching farms and two encouragement assignments.
encouragement = np.array([-2.,-1.5,-1.,-.5,0.,.5,1.,1.5,2.,2.5])
reminder = np.array([-1.,.8,-.6,.4,-.2,.1,.3,-.5,.7,-.9])
dose = np.array([1.2,1.8,1.5,2.8,2.7,3.7,3.4,4.2,4.5,5.3])
harvest = np.array([3.1,3.5,3.0,5.2,4.0,5.6,5.4,6.8,6.5,8.0])
n = len(dose)
controls = np.ones((n,1))
excluded = np.column_stack([encouragement,reminder])
full = np.column_stack([controls,excluded])
q = excluded.shape[1]
df = n-full.shape[1]
def residual(y, design):
    return y-design@np.linalg.lstsq(design,y,rcond=None)[0]
ry, rd = residual(harvest,controls), residual(dose,controls)
uy, ud = residual(harvest,full), residual(dose,full)
critical = f.ppf(.95,q,df)
# F(beta)=((SSR_R-SSR_U)/q)/(SSR_U/df). Retain both degrees of freedom.
k = q*critical/df
A = rd@rd-(1+k)*(ud@ud)
B = -2*(ry@rd-(1+k)*(uy@ud))
C = ry@ry-(1+k)*(uy@uy)
# This example is nondegenerate with two real boundaries. Derive its shape.
discriminant = B*B-4*A*C
assert abs(A)>1e-10 and discriminant>0
boundaries = np.sort(np.roots([A,B,C]).real)
unbounded = int(A<0)
# A>0 accepts between the boundaries. A<0 accepts both outer rays.
def accepts(beta):
    return A*beta*beta+B*beta+C<=0
def direct_F(beta):
    r, u = residual(harvest-beta*dose,controls), residual(harvest-beta*dose,full)
    return ((r@r-u@u)/q)/((u@u)/df)
for boundary in boundaries:
    assert np.isclose(direct_F(boundary),critical,atol=1e-8)
for beta in [boundaries[0]-1,boundaries.mean(),boundaries[1]+1,0.]:
    assert accepts(beta)==(direct_F(beta)<=critical)
rows = [
 {'term':'fertilizer_boundary_low','estimate':float(boundaries[0]),'se':None,'n_obs':n},
 {'term':'fertilizer_boundary_high','estimate':float(boundaries[1]),'se':None,'n_obs':n},
 {'term':'fertilizer_accepts_zero','estimate':int(accepts(0.)),'se':None,'n_obs':n},
 {'term':'fertilizer_unbounded','estimate':unbounded,'se':None,'n_obs':n}]
with open('example_result.json','w') as stream:
    json.dump({'task_id':'fertilizer_two_encouragement_ar','estimates':rows},stream,indent=2,allow_nan=False)
```
